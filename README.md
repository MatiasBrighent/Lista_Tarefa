## Descrição do Projeto
  
  Site criado como exércicio para pratica de JQuery. Exércicio consistia em criar uma lista de tarefas, onde o usuário adiciona uma atividade que ele precisa realizar e a salva, após concluir a tarefa o usuário pode optar por riscar ou apagar a atividade realizada da lista, há tambem a opção de apagar todos os itens adicionados.
